# Telco Customer Churn Prediction

Built a machine learning binary classification model to predict whether telecom customers will churn.

## Project Overview

This project uses Logistic Regression to classify customers as:

* 0 = Stay
* 1 = Churn

## Dataset

Telco Customer Churn Dataset-> from kaggle
7032 rows, 23 columns

## Steps Performed

* Data Cleaning
* Missing Value Handling
* Encoding Categorical Features
* Feature Scaling
* Train-Test Split
* Logistic Regression Model
* Performance Evaluation

## Model Performance

* Accuracy: 81.3%
* Precision (Churn): 0.67
* Recall (Churn): 0.58
* F1-score (Churn): 0.62
